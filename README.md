# Welcome to My Imdb Api
***

## Task
The goal of this project was to build a REST API using Flask that serves movie data from the IMDb dataset and allows users to filter movies by genre through different endpoints. The challenge was not only reading and processing CSV data, but also understanding how web APIs exchange information and how automated tests validate responses.

One of the main difficulties was handling the response format correctly. While the application logic could successfully filter the movies, the testing framework expected the returned data to follow a very specific JSON structure. During development, a significant amount of debugging was spent comparing the expected response format with the actual response generated by Flask.

Another challenge involved understanding how genres are stored in the dataset. Many movies belong to multiple genres such as "Action,Adventure,Western" or "Comedy,Romance,Western". Simple equality comparisons often produced incorrect results because the route needed to determine whether a genre was present inside a comma-separated list rather than matching the entire string.

A final challenge was making the API reachable by the testing environment. The Flask server must listen on 0.0.0.0 and port 8080; otherwise the routes cannot be accessed by the automated tests even if the application works locally.
## Description
The application uses Flask to expose multiple routes for filtering movies by genre. Movie data is loaded from the IMDb dataset hosted online and parsed using Python's csv.DictReader.

Each row of the CSV file is converted into a dictionary where the column names become keys. These dictionaries are collected into lists and returned through Flask routes.

Several debugging and implementation issues were solved during development:

Understanding that csv.DictReader returns dictionaries rather than strings.
Learning that the collection of movies is therefore a list of dictionaries (list[dict]).
Ensuring requests use the correct query parameters when accessing the root endpoint.
Serving the application on 0.0.0.0:8080 so external tests can reach the routes.
Verifying route behavior using direct HTTP requests.
Comparing returned JSON objects against the expected test responses.
Handling empty CSV values which may appear as empty strings and need to be represented properly in JSON responses.
Investigating how Flask's jsonify() serializes Python data structures into JSON responses.
Debugging automated test failures by carefully checking counts, JSON structure, and response formatting.

The final API provides endpoints for:

/
/action
/adventure
/comedy
/drama
/romance

The root route supports filtering through query parameters while the dedicated routes return movies belonging to specific genres.
## Installation
Clone the repository and install the required dependencies:
```md 
pip install flask**
```
The project also uses standard Python libraries:
```python
csv
urllib.request
json
```
No additional database or external services are required.Fetching the csv file form the link provided:
https://storage.googleapis.com/qwasar-public/track-ds/imdb-movie-data.csv

## Usage
Start the server:
```md
python app.py
```

Example requests:

Retrieve all movies:
```md
http://localhost:8080/
```
Filter movies by genre using a query parameter:
http://localhost:8080/?genre=western

Get action movies:
http://localhost:8080/action

and so on 
Responses are returned in string format.
